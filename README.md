# Content System

This is the public release repository for Nicole Weiss.

The private working repository is the canonical source for active development.
This repository contains only material that has passed the project's privacy,
security, and licensing review. It is released deliberately and may lag behind
the working source.

The system is designed to help a content operator capture ideas, triage them,
develop useful work, learn from published content, and automate repetitive
operations only after the workflows are reliable.

The first public release is not yet published. No private content, raw exports,
analytics, research, client information, credentials, or live secrets belong in
this repository.
